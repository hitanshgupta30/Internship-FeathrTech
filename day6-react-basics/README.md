# Day 6 React Basics - Task Manager

## Project Purpose

This project is a Task Management Dashboard built using React and Vite.

The application allows users to:
- View tasks
- Add tasks
- Delete tasks
- Change task status
- Search tasks
- Filter tasks
- View task details
- Switch between light and dark themes
